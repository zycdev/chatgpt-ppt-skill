# Slide 7 — 研究内容二｜认知缺口驱动的智能体行动目标自主调节

## Canvas
- One complete 16:9 PowerPoint slide image.
- Language: Simplified Chinese.
- Do not render a slide number, watermark, fake citation, or unrelated logo.

## Deck goal and audience
Formal research-project defense for an expert review panel. The deck explains how a single autonomous agent achieves continual self-improvement through the “知—行—学” loop. This slide must make the **knowledge-seeking goal regulation mechanism** understandable at a glance while retaining a serious academic tone.

## Slide role and intent
This is a core method slide. It should answer:

**When the agent discovers that its current cognition is insufficient, how does it turn that gap into a worthwhile knowledge-seeking action without derailing the original task?**

The audience should understand the mechanism in about 10 seconds, then be able to inspect the four stages in more detail.

## Exact visible text
Render the following wording exactly and legibly.

**Title**
研究内容二｜认知缺口驱动的智能体行动目标自主调节

**Four mechanism stages**
1. 认知缺口检测
2. 求知目标构建
3. 行动价值评估
4. 多目标竞争与调节

**Value expression**
任务收益 + 未来认知收益 − 交互成本 / 风险

**Bottom takeaway**
在不打断主任务的前提下，决定何时插入、延后或恢复求知行动

Do not add invented technical terms or filler copy.

## Semantic relationships
The visual must communicate the following logic:

- The agent starts from the current task state and existing cognition.
- A conflict, uncertainty, missing fact, or unclear boundary reveals a **认知缺口**.
- The gap is transformed into an explicit knowledge-seeking goal with a question/evidence need/completion condition.
- The agent evaluates the value of acting now by jointly considering task benefit, future cognitive benefit, interaction cost, and risk.
- The knowledge-seeking goal competes with the original task goal.
- The agent chooses to **插入 / 延后 / 恢复** the knowledge-seeking action.
- New evidence returns to later cognition/decision making; show a subtle feedback path without cluttering the main flow.

## Composition
Create **one dominant horizontal mechanism flow** across the middle of the slide, with the four stages visually connected as a single process rather than four unrelated cards.

Suggested visual rhythm:
- left: small “认知缺口” trigger area with restrained icons for conflict / uncertainty / missing evidence;
- center: the four-stage mechanism as the main visual spine;
- under “行动价值评估”: a compact visual balance/decision motif carrying the value expression;
- right: a branching decision showing 插入 / 延后 / 恢复;
- a light feedback arrow returns from acquired evidence toward cognition, clearly separated from all text.

Use visual grouping and arrows to explain the mechanism. Avoid a dashboard of equal boxes.

## Text repairability
Every text-bearing region must be independently coverable later.

- Place all text on white or flat solid-color local backgrounds.
- No gradient, texture, illustration detail, diagram line, arrow, icon, or connector may pass behind text.
- Keep generous padding around the long title and the four stage labels.
- Keep the value expression in a clean flat zone, not on top of the balance graphic.
- Apply the overlay test: a rectangle roughly 20% larger than each text block should not damage nearby graphics or another text block.
- Do not interpret this as “put everything in cards”; open white space is preferred where possible.
