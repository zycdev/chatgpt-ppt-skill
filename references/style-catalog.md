# Built-in Style Directions

Use these as starting directions, not rigid templates. All styles must obey repair-safe text zones.

1. **Academic Light Infographic** — white background, restrained pastel accents, clean scientific diagrams, generous whitespace.
2. **Minimal Research** — typography-led, very sparse, thin rules, flat-color emphasis blocks, conference-talk feel.
3. **Editorial Science** — magazine-like composition, strong hierarchy, large figures, asymmetrical but controlled layout.
4. **Soft Isometric Tech** — subtle 3D/isometric objects, soft shadows, clean flat text zones, modern AI/technology feel.
5. **Technical Blueprint Light** — precise schematic language, grids/lines in non-text zones, pale technical palette.
6. **Clean Corporate** — professional, structured, spacious, understated icons and diagrams, low visual noise.
7. **Data Story** — large evidence/metric focus, simplified charts and annotated callouts, strong numeric hierarchy.
8. **Geometric Modular** — flat geometric motifs, modular composition, crisp edges, modern institutional feel.
9. **Hand-drawn Scientific Infographic** — lightly illustrated/hand-drawn objects with clean flat text zones and controlled annotation.
10. **Elegant Paper & Ink** — subtle paper-like decoration only outside text zones, refined line art, editorial restraint.
11. **Dark Technical** — dark flat base with solid text panels/zones, luminous technical accents, no gradients behind text.
12. **Keynote Poster** — bold single-message composition, large typography, one dominant visual metaphor, minimal supporting text.

When proposing styles, select only 2–3 that fit the content/audience.
