# Style Reuse

This skill contains only static built-in visual directions.

Use user-supplied style references when explicitly available, including screenshots, PPT/PDF pages, or previously saved assets accessible in the current task environment.

Do not automatically create, mutate, or assume a persistent personal style library.

Long-term style persistence is outside the core workflow. If such a store becomes available later, treat it as an external style source rather than part of the skill engine itself.
